Slice 3 · Workspace

Ref sidebar

Collapsible .sidebar__section groups (LOCAL / REMOTE / TAGS / WORKTREES / STASHES). Each __header has a caret + count; .is-current rows show a check, and ahead/behind render as __chips. Toggle a section with the demo buttons.

Slice 3 · Workspace

Top action bar (.toolbar2)

Grouped stacked icon+label buttons separated by __sep, plus repo / branch __select triggers. .is-active marks a toggled tool (e.g. Terminal); [disabled] dims unavailable actions (Redo).

Slice 3 · Workspace

Right-click context menu (.ctxmenu)

Reusable menu with __item rows (icon + label + optional __shortcut), __sep dividers, --danger items, and a nested __submenu (Reset ▸ Soft/Mixed/Hard). Keyboard-navigable via .is-active / :focus-visible. Shown statically (normally position:absolute at the cursor).

Slice 3 · Workspace

Commit detail panel

Right-pane content for the selected commit: header (subject / sha / author / date), full message __body, and a .file-list of changed files with a status glyph and add/del counts.

Notifications inbox & issue detail

The GitHub view: a two-pane .gh-layout (list | detail). The list shows .gh-list__rows with a .gh-list__reason chip (--mention / --assign / --review / --comment), repo + title and time; .is-unread rows get an accent rail and a brighter title. A row click opens it in the .gh-detail pane.
